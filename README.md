# XCeed: 72 Hours to Act — v4

Static website for GitHub Pages. Upload **index.html**, **styles.css**, and **app.js** to the repository root.

## Game flow
Welcome → Situation → Rules and budget → Nine objectives → Allocate six roles → Resource marketplace → Crisis 1 (minute 7) → 3 trivia questions → Crisis 2 → 3 trivia questions → Crisis 3 → 3 trivia questions → free-form Amnesty handover.

Only the Team Leader operates the computer. Banker handles resource planning; Medical Lead advises on science, Legal Lead on Islamic history, Advocacy Lead on Islamic deen, Handover Lead takes notes.

Each of the nine objectives is earned by answering its trivia question correctly. Questions are genuinely different across difficulty tiers (hard, medium, easy). Resource upgrades are allowed after seeing a question, before submitting an answer. Starting cash is £10,000. Amnesty considers the handover if at least 6/9 objectives are completed.

No visible finance tracker, action log, or SBAR template. Money still applies internally to buying/refunding resources and crisis decisions. The resource marketplace shows prices and refunds.

Game progress is stored in browser localStorage under xceed72-v4. Reset Game starts a fresh run. The game is fictional; no Amnesty affiliation is implied.
